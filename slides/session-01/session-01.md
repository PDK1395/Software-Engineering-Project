# Definition of Done

یک کار وقتی «تمام» است که:

- کد نوشته شده و Merge شده
- تست دارد و پاس می‌شود
- Code Review شده
- مستندات به‌روز است
- در محیط Demo کار می‌کند

---

# نقش‌ها در تیم

- **Product Owner:** تصمیم می‌گیرد چه چیزی بسازیم
- **Scrum Master:** جلسات و موانع را مدیریت می‌کند
- **Developer:** کد می‌نویسد
- **Tester:** کیفیت را تضمین می‌کند

**نقش‌ها هر Sprint می‌چرخند.**

---

# قوانین همکاری

- تأخیر در تحویل = تأثیر روی نمرهٔ تیم
- غیبت مکرر = حذف از تیم (در موارد شدید)
- سهم نابرابر = گزارش به استاد
- استفاده از AI: مجاز، اما با شفافیت
- کپی از تیم دیگر = نمرهٔ صفر برای هر دو تیم

---

# ابزارها

- **Figma** — طراحی UI
- **draw.io** — دیاگرام
