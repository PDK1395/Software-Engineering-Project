# اسلایدهای پروژه

این پوشه محل ارائهٔ معرفی TrackFlow، مسئله، کاربران، گردش اسکن بارکد، معماری، دموی محصول و برنامهٔ توسعه است. هنوز فایل ارائه‌ای در این پروژه قرار داده نشده است.

پیشنهاد چینش: ۱) مسئله و چشم‌انداز، ۲) پرسوناها، ۳) گردش اصلی فروش، ۴) نیازمندی‌ها و معماری، ۵) نمونهٔ اولیه، ۶) ریسک‌ها و نقشهٔ راه. از اطلاعات مشتری واقعی در اسلایدها استفاده نکنید.
